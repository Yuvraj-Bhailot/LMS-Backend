# Library Management System

A Java-based backend application developed using Spring Boot to manage library operations through RESTful APIs.

## 📌 About the Project

The Library Management System is a backend application built using Java and Spring Boot. It is designed to provide a structured and efficient way to manage library-related operations.

The project follows a layered backend architecture and uses Spring Data JPA for database interaction, PostgreSQL for data storage, and REST APIs for communication.

## 🚀 Features

- RESTful API development using Spring Boot.
- Database integration using Spring Data JPA.
- PostgreSQL database connectivity.
- Object mapping using ModelMapper.
- Input validation using Spring Boot Validation.
- API documentation using Swagger UI / OpenAPI.
- Simplified Java code using Lombok.

## 🛠️ Technologies Used

- **Java 21** – Core programming language.
- **Spring Boot** – Backend application framework.
- **Spring Data JPA** – Database operations and persistence.
- **PostgreSQL** – Relational database management system.
- **Hibernate** – ORM implementation.
- **Maven** – Dependency management and build automation.
- **Lombok** – Reduces boilerplate Java code.
- **ModelMapper** – Object-to-object mapping.
- **Spring Boot Validation** – Input validation.
- **Springdoc OpenAPI** – API documentation and Swagger UI.

## ⚙️ Prerequisites

Before running the project, make sure you have:

- Java Development Kit (JDK) 21.
- PostgreSQL installed and configured.
- Apache Maven.
- Eclipse IDE / IntelliJ IDEA / Spring Tool Suite.

## 📖 API Documentation

The project includes Springdoc OpenAPI for API documentation.

Once the application is running, access Swagger UI at:

```text
http://localhost:8080/swagger-ui/index.html
```
